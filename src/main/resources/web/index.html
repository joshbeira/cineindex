BEHIND THE INDEX

Small engine.
Interesting internals.

CineIndex connects movie metadata, audience ratings, and film credits through custom Java data structures.

01

Find it

Chained hash tables connect film IDs to metadata and maintain film-to-person indexes.

02

Rank it

AVL trees order results. Cached rating sums make averages available without rescanning every review.

03

Connect it

Similar films share genres and cast. Each suggestion explains exactly why it appears.

An in-memory, read-only local application. Import data at startup; restart to load a different catalogue.
