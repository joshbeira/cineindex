# Changelog

## 1.0.0 — 2026-09-21

- Movie discovery dashboard with search, genre filters, rankings and pagination.
- Read-only JSON API, cast filmographies and rating distributions.
- Explainable recommendations based on shared genres and cast.
- Custom hash tables, hash sets, linked sequences and AVL trees.
- Incremental rating aggregates and consistent bidirectional deletion.
- JSON and CSV imports, with a self-contained fictional demo.
- Deterministic benchmark workload, regression tests, coverage reports and CI.
